# 🎵 Spotify Clone

A simple **Spotify Web Player UI Clone** built using HTML and CSS. This project recreates the basic look and layout of Spotify's web player, including the sidebar, music cards, navigation bar, and music player controls.

## ✨ Features

- **Sidebar Navigation:** Home, Search, and Your Library sections.
- **Playlist Section:** Options to create a playlist and browse podcasts.
- **Sticky Navigation Bar:** Includes Explore Premium, Install App, and user icons.
- **Recently Played:** Displays music cards.
- **Trending Now:** Shows trending music cards.
- **Featured Charts:** Displays global and India song charts.
- **Music Player UI:** Includes playback controls and a progress bar.
- **Responsive Design:** Includes basic CSS media queries for smaller screens.

## 🛠️ Technologies Used

- HTML5
- CSS3
- Font Awesome
- Google Fonts (Montserrat and Poppins)

## 🚀 How to Run the Project

1. Clone this repository:

   ```bash
   git clone https://github.com/sumanraj-25/Spotify-clone.git
   ```

2. Open the project folder in VS Code.

3. Open `index.html` in your browser, or use the Live Server extension in VS Code.

## 🎯 Project Purpose

The main purpose of this project is to practice HTML and CSS by recreating a familiar music streaming interface and learning about layouts, Flexbox, cards, positioning, and responsive design.
